# vrperf v1.11.0

First public stable AMD release under GPL-3.0-only.

This package uses the tested v1.10.0 application code, with updated version and licence metadata. The Arch Linux / AMD RX 9070 XT / Steam Frame configuration passed 25 unit tests and headset testing for v1.10.0. This GPL-licensed package has not been compiled or tested separately.

## Included

- CPU and GPU frame-time graphs, frame budget, FPS and dropped-frame markers.
- Hardware statistics, battery percentages, clock and resolution setting where available.
- SteamVR dashboard ON/OFF toggle, autostart and ~/.local/bin install.
- Best-effort NVIDIA NVML and Intel Level Zero support, untested.

AMD RX 9070 XT / RADV is the tested configuration. Other AMD models and all NVIDIA/Intel configurations are untested. Prebuilt Ubuntu-hosted Linux binary is not tested on the reference Arch machine. See README for installation and limits.
